# 群岛岛屿坐标表（模板 / 前置确认资料）

> 用途：当要把「装饰性海图背景」换成「画有具体岛屿的背景图」时，用本表把每座岛的按钮
> 精确摆到背景里画出来的岛屿上。当前版本背景是通用海图（无绘制岛屿），岛屿按钮是
> `lib/worldLayout.ts` 的算法坐标叠加层，因此**现在不需要**填本表也能跑；本表是给
> 「日后换成带岛屿插画的背景图」时用的对齐工具。

## 规则
- 坐标用**百分比**（相对背景容器左上角，x 向右、y 向下），与 `WorldNode.x / WorldNode.y` 一致。
- 一座岛对应一个 MK 元认知（`岛名 = 元认知名 + "岛"`）。
- 背景图固定按 16:9 显示（`WorldMap` / `WorldAtlas` 均已 `aspect-[16/9]` 锁比例），
  填表时请以 16:9 画布为基准。
- `群岛页` 决定用哪张背景图（`lib/archipelagoLayout.ts` 的 `getArchipelagoBg`）：
  `arch_01`~`arch_07` 分别对应页 1~7。

## 当前（算法）坐标对照（无需填表也可运行；仅作参考）
当前岛屿位置由 `getWorldLayout()` 按进化谱系自动算：
- `x = 8 + i*84/(同层节点数-1)`（同层横向均分，8%~92%）
- `y = 86 - depth*(74/maxDepth)`（父岛在下、子岛在上）

三场景（主界面默认 / AI 助手最小化 / 全览缩略图）**共用同一套 x/y%**，
且地图区与缩略图均已锁定 16:9，故按钮相对背景不错位、不重叠。

## 何时需要我填表 / 改坐标
只有当你提供「带绘制岛屿的背景图」（或带编号参考图）时，才需要：
1. 按设计稿量出每座岛中心在 16:9 画布上的 x/y%；
2. 填入上表并交回；
3. 我把 `getWorldLayout()` 改为读取此表（或直接在 `worldNodes` 构建处覆盖 x/y）。
