## 〇、背景与现状

### 现状（v1.1.8）
- 地图：一整张海图，29 座岛按进化谱系绝对定位（x/y 百分比），点岛→聚焦进入单岛。
- 路由 10 个：`/` `/ask` `/battle` `/boss` `/brain` `/growth` `/journal` `/onboarding` `/parent` `/spirits`。
- 顶部导航（BottomNav.tsx）：5 tab —— 地图 / 精灵 / 好奇心 / 成长 / 图鉴。
- HUD：左上 `card` 岛屿名+统计；右上 6 个按钮 + 头像（进化路线/火花/家长/设置/头像）。
- DAG：29 岛，depth 0-5（2/8/7/5/4/3），双起点 MK-01/MK-15，16 个叶子。

### 发起人的诉求（本轮）
1. **地图左右拖动 / 箭头换页**（告别一屏装 29 岛）+ **全览模式**。
2. **顶栏重组**：右上角 = 头像（"我的"入口），主 tab 不再被"成长/图鉴"挤占。
3. **AI 交流可达**：要么在中间主区切换"地图 / AI 聊"两个 tab，要么左地图 + 右 AI 聊的分屏。
4. **保留并重排**：设置 / 家长 / 精灵 / 图鉴（含进化路线 + 已得精灵）—— 这些是次要入口，不该霸占主 tab。

### 发起人的本轮新增需求（5 条 + 1 待定）
5. **小学生 UI**：整体偏大、字体偏大（让小孩独立可点可读）。
6. **次要 tab 全收"我的"**：右上头像 hover/click → 向下展开抽屉，承载设置/家长/精灵/图鉴。
7. **主界面布局可切**：设置里让用户选「双 tab（窄屏）」或「左地图+右 AI（宽屏）」。
8. **地图按设计稿页面分页**：5 张岛屿插画左右铺开，黑边框包裹，**左右两侧放箭头**，**左下角放全览图标**点击看 29 岛总览（全览 UI 我自己设计，遵循已有地图插画风格）。
9. **logo 占位**：先用一个小图标占位，后期替换。
10. **探险家等级**：用户问"等级是什么，我应该还没有设定过"——**确实未设定**（`explorer` 表只有 id/name/brain_settings/current_island/difficulty_bias，**无 level 字段**），本方案定一套。

## 一、小学生友好的 UI 尺寸规范（必做 · 改动最大）

### 1.1 基准尺寸（Kano 模型 + Apple HIG Kids）
儿童（6-12 岁）指尖触点 ~12mm（成人 9mm），目标点击区 ≥ 44×44 CSS px，**实际建议 56×56**；最小字号 16px，**正文 18px**，**标题 24px+**。

| 元素 | 当前 | 目标 | 备注 |
|---|---|---|---|
| body 字号 | 14px | **18px** | +28% |
| 标题 h1 | 20-24px | **28-32px** | .font-story |
| 标题 h2 | 16-18px | **22-24px** | .font-story |
| 按钮 | h-9 / text-sm | **h-14 / text-lg** | min-tap 56px |
| 顶 tab 图标 | text-xl | **text-2xl** | +33% |
| 顶 tab 文字 | text-xs | **text-base** | +33% |
| 岛屿节点 | h-16 w-16 | **h-20 w-20** | 80×80 |
| 卡片 padding | p-3 / p-4 | **p-5** | +25% |
| 头像菜单 | h-12 w-12 | **h-14 w-14** | 56×56 |
| 左右翻页箭头 | h-12 w-12 | **h-16 w-16** | 64×64 |

### 1.2 触摸目标
- 所有可点击元素 `min-w-14 min-h-14`（56×56）
- 间距 `gap-3` → `gap-4`（防误触）

### 1.3 文字 + 图标
- **图标 + 文字双标签**永远同时出现（不只 emoji）
- `font-story`（ZCOOL KuaiLe）只用于：① 顶栏 logo/标题 ② 岛屿名 ③ 弹窗标题 ④ 头像菜单项；**正文保留系统字体**保可读性

### 1.4 实施：新增 `globals.css` 大尺寸变量
```css
:root {
  --tap-min: 56px;
  --fs-body: 18px;
  --fs-h1: 30px;
  --fs-h2: 24px;
  --fs-btn: 18px;
}
```
所有按钮 / 卡片 padding / 字号改为引用变量，方便后续再调。

## 二、探险家等级设定（v1 设计）

### 2.1 现状
- `explorer` 表**没有 level 字段**
- 现有 `growth_log` 表记录了 13+ 种成长事件（净化 Boss / 觉醒 / 守护战赢 / 火花 +1 / 答对 / 卡关等）
- 火花数（sparks.total）已经是单一量化指标

### 2.2 等级定义（6 档 · 渐进命名）

| 等级 | 头衔 | 升级条件 | 解锁内容 |
|---|---|---|---|
| **Lv.1 学员** | 🧭 海岛新丁 | 起始 | 计数岛 + 图形岛（MK-01/MK-15） |
| **Lv.2 学徒** | 🌱 海岸探险 | 净化 3 个 Boss 或火花 ≥ 30 | 解锁"全览缩略图" |
| **Lv.3 学士** | 📚 海图学者 | 净化 8 个 Boss 或火花 ≥ 100 | 解锁"进化树"+"双 tab/分屏"切换 |
| **Lv.4 大师** | 🏆 海图大师 | 净化 16 个 Boss 或火花 ≥ 250 | 解锁"AI 自由提问"（解除火花限制） |
| **Lv.5 宗师** | 🌟 海图宗师 | 净化 25 个 Boss 或火花 ≥ 500 | 解锁"自定义头像"+"个性化主题色" |
| **Lv.6 传奇** | 👑 知识岛屿主 | 净化全部 29 个 Boss | 解锁"专属彩蛋"+ 装饰称号 |

### 2.3 实现
- `db.ts`：`ALTER TABLE explorer ADD COLUMN level INTEGER NOT NULL DEFAULT 1` + `xp INTEGER NOT NULL DEFAULT 0` + `title TEXT`
- `repo.ts`：`getExplorerLevel()` + `levelFromXp(xp)`（xp = 火花数）
- 等级提升：服务端检测、刷出"恭喜晋升 🎉"动画、写入 growth_log
- 前端：头像菜单顶部展示 🏆 Lv.4 海图大师 + 火花进度条

### 2.4 头像菜单整合（统一在新版外壳里）
```
[🧭 头像 + Lv.4 海图大师]
       │
       ▼ 点击/hover
┌─────────────────────────────────────┐
│ 🧭 我的探险家                        │
│   Lv.4 海图大师  ✨250  →  Lv.5 差 250│
├─────────────────────────────────────┤
│ 📚 精灵图鉴       📖 知识家园        │
│ 👨‍👩‍👧 家长端        🏆 成就            │
│ ⚙️ 设置           💤 退出            │
└─────────────────────────────────────┘
```
- 默认**点击展开**（hover 在移动端不可靠），CSS-only hover 兜底（桌面）
- 抽屉从右上向下展开，宽度 ~280px，停在顶栏下方

## 三、外壳（Top Shell）方案

### 3.1 信息架构（5 条新需求整合后）

发起人原话拆解：
> "最上面一行是 tab 栏，右上角是我们的小探险家头像也就是'我的'"
> "中间的 tab 可以切换地图和 ai 聊天"
> "tab 栏再加上设置，家长端，精灵界面，以及我们的图鉴或者说家园，可以呈现进化路线和每一只已经获得的精灵"

→ **最终方案：主 tab + 头像抽屉**

```
主 tab（中间切换，主区域）：
  1. 🗺️ 地图
  2. 💬 跟小狐狸聊（AI）

  📖 知识家园
  🏆 成就
  👨‍👩‍👧 家长端
  ⚙️ 设置（含布局切换："双 tab" / "左地图+右 AI"）
```

### 3.2 三种外壳布局（设置里可切）

#### 方案 1 · 顶双层 Tab（默认 · 窄屏 / 安全）

```
┌───────────────────────────────────────────────────────┐
│ [🏝️ logo]  [🗺️地图][💬AI]   ……  [✨3][⚙️][🧭Lv.4] │ ← 主 tab 中
├───────────────────────────────────────────────────────┤
│                                                       │
│   主内容（地图全宽 or AI 聊全宽，二选一）                │
│                                                       │
└───────────────────────────────────────────────────────┘
```
- 优点：最稳，窄屏（手机/平板竖屏）下唯一可用
- 默认选项

#### 方案 2 · 左地图 + 右 AI 聊（宽屏 ≥1280px）

```
┌───────────────────────────────────────────────────────┐
│ [🏝️ logo]                ……  [✨3][⚙️][🧭Lv.4]      │
├──────────────────────────┬────────────────────────────┤
│   🗺️ 地图（60%宽）        │   💬 AI 聊（40%宽）         │
│                          │                            │
│   ◀ [页2/5] ▶             │   历史对话                  │
│   [设计稿岛屿插画铺开]    │   输入框                    │
│                          │   快捷问题                  │
│   [🔍 全览] 左下角         │                            │
└──────────────────────────┴────────────────────────────┘
```
- 优点：边玩边问，"陪伴"感最强
- 缺点：<1280px 自动折叠为方案 1

#### 方案 3 · 三栏自适应（高级 · 三阶段渐进）

| 屏宽 | 布局 |
|---|---|
| ≥1440px | 左缩略图 + 主地图 + 右 AI 聊 |
| 1024-1440px | 主地图 + 右 AI 聊（无左缩略图） |
| <1024px | 顶 tab 二选一全宽 |

### 3.3 推荐
**方案 1（默认）+ 方案 2（≥1280px 自适应）**：
- 实现简单（一个 `useMediaQuery` 断点）
- 暗黑 + 大屏都给体验
- 不上方案 3：复杂度不划算，等真用户反馈再决定

## 四、地图（第一层）改造方案

### 4.1 设计稿页面编号与岛屿页对应

| 页面编号 | 推测领域 | 张数 | 备注 |
|---|---|---|---|
| 1-1 / 1-2 | 计数岛起点 | 2 | 双起点之一（MK-01） |
| 2-1 ~ 2-5 | 运算族 | 5 | 加减乘除 + 估算 |
| 3-1 ~ 3-5 | 图形族 | 5 | 双起点之二（MK-15）+ 4 衍生 |
| 4-1 ~ 4-4 | 测量族 | 4 | 长/重/容积/时间 |
| 6 / 7 / 8 / 9 | 应用 / 广角 | 4 | 待设计师确认 |
| **合计** | | **20** | 实际 22 张（1 张疑似重复） |

> 阻塞：需要发起人或设计师逐张标注"页面→岛屿"对应才能填 `ISLAND_ART` 精确表（当前走默认循环）

### 4.2 地图三层模式（必须并存）

| 模式 | 触发 | 用途 |
|---|---|---|
| **A. 分页地图（主 · 5 页）** | ◀ ▶ 箭头 or 拖动 | 逐片探索 29 岛，每页 5-8 岛 |
| **B. 全览缩略图** | 左下角 🔍 图标 | 一屏看 29 岛位置关系（卫星图） |
| **C. 谱系树** | 顶栏"进化路线"按钮（保留现有） | 滚动浏览所有进化路线 |

### 4.3 分页地图（A）的具体设计

**分页策略**：按 **depth** 自然分页（双起点独立首页 + depth1-4 横向）
- **页 1**：起点页（双起点岛 + 周边）
- **页 2-4**：按 depth 1/2/3 各 8/7/5 个岛
- **页 5**：depth 4+5 合并 7 个岛（避免页数过多）
- **共 5 页**

**页面内布局**：
- **黑边框包裹**（.card `border-4 border-[#2b3a4a]`，厚度大、显眼）
- 上半页：横向回流排列 2-8 个岛（环形 / Z 字 / 螺旋）
- 岛间**白虚线**是进化路线（保留）
- 当前玩家化身站在本页"主角"岛上
- **左右两侧大圆箭头** ◀ ▶（64×64，青绿底，hover 放大）
- **左下角全览图标** 🔍（56×56，点击切到 B 模式）
- **底部页指示器**：5 个圆点，当前页橙色高亮
- **上下页之间**：跨页进化线箭头 ↶ / ↷（强化"本领跨层演进"）

### 4.4 全览缩略图（B）
- 一屏塞 29 个迷你缩略图（每张 ~40px），全部按现有 x/y% 缩小
- 当前岛橙色脉冲；已解锁彩色、未解锁灰雾带🔒
- 顶部小输入：可按"已解锁/未解锁/全部"过滤
- 底部按钮："返回分页地图"
- **全览模式点岛 → 跳到分页地图对应页 + 自动聚焦该岛**

### 4.5 与聚焦态（L2 战斗地图）的关系
- 分页地图点岛 → `setFocused(island)` 进入 L2
- 全览模式点岛 → 同上 + 自动切到对应页
DAG 结构定死了"双起点 → 5 层"：
```
depth=0: [MK-01 计数, MK-15 图形]      (2)
depth=1: 8 个孩子
depth=2: 7 个孩子
depth=3: 5 个孩子
depth=4: 4 个孩子
depth=5: 3 个孩子（最终叶子）
```

### 1.2 三种地图模式（必须并存）

| 模式 | 触发 | 用途 |
|---|---|---|
| **A. 分页地图（主）** | 左/右箭头 or 拖动 | 逐片探索 29 岛，每页 6-8 岛 |
| **B. 全览缩略图** | 顶栏切换按钮 | 一屏看 29 岛的位置关系（"卫星图"） |
| **C. 谱系树** | 已有 EvolutionPathButton | 滚动浏览所有进化路线（学术向） |

### 1.3 分页地图（A）的关键设计

**分页策略**：按**深度**自然分页最直观 —— 同 depth 的岛在同一页（因为 DAG 同层是横向并排的）。

- **页 1（depth=0）**：起点页（计数 + 图形双起点）
- **页 2（depth=1）**：8 个第 1 层孩子
- **页 3（depth=2）**：7 个
- **页 4（depth=3）**：5 个
- **页 5（depth=4+5）**：7 个（合并两层避免页数过多）

→ **共 5 页**，每页 2-8 岛，节奏舒服。

**页面布局**（每页内）：
- 上半页：横向回流排列 2-8 个岛（环形 / Z 字 / 螺旋）
- 岛间白虚线是进化路线（保留）
- 当前玩家化身站在本页"主角"岛上
- 上下页之间用**大箭头** ↶ / ↷ 跨页进化（强化"本领跨层演进"的隐喻）
- 左右箭头 ◀ ▶ 切页

**左/右箭头**：
- 始终显示在地图左右两侧，大圆按钮，半透明青绿底
- hover 放大、点击有弹跳反馈
- 第 1 页禁用 ◀、最后页禁用 ▶
- 拖动 ≥40px 触发翻页（带 inertia snap）

**页指示器**：底部 5 个圆点，当前页橙色高亮，可点击跳转。

### 1.4 全览缩略图（B）

- 一屏塞 29 个迷你缩略图（每张 ~40px），全部按现有 x/y 比例缩小
- 当前岛橙色脉冲；已解锁彩色、未解锁灰雾带🔒
- 顶部小输入：可按"已解锁/未解锁/全部"过滤
- 底部一个按钮："返回分页地图"
- **关键：全览模式下点击单岛 → 跳到分页地图的对应页 + 自动聚焦该岛**

### 1.5 与聚焦态（L2 战斗地图）的关系
- 不变：分页地图点岛 → 仍走 WorldMap 的 `setFocused(island)` 进入 L2
- 全览模式点岛 → 同上 + 同时切换到对应页

**主 tab 区**（占据中间主区域切换，2 个）：

- 优点：边玩边问，AI 是"陪伴"而非"切换的另一个 app"
- 缺点：地图水平空间被压缩（500px 左右）；窄屏体验差，需要可折叠的右栏
- 适用：发起人第二个原话"或者我们可以吧主界面设计成左右两部分，左边是地图，右边是ai交流的地方，方便学生试试访问"

#### 方案 C · 三栏自适应（最灵活 — 实现复杂）

```
桌面（>1280px）：
┌─────────────────────────────────────────────────────────────┐
│ [logo 🏝️] [🗺️地图][💬AI聊]   …………  [✨3][⚙️][🧭 我的]       │
├──────────┬─────────────────────────────┬───────────────────┤
│ 🗺       │                             │ 💬               │
│ 全览     │   主地图（分页）             │   AI 聊           │
│ 缩略图   │                             │                   │
│ 29 岛    │                             │                   │
└──────────┴─────────────────────────────┴───────────────────┘
平板（768-1280）：左缩略图自动收起为图标条
手机（<768px）：地图/AI 切换为 tab，单栏
```
- 优点：信息密度最高，"探索+陪伴+全局感" 同时给
- 缺点：响应式断点 3 个、组件状态多、实现成本是 A 的 2-3 倍
- 适用：黑客松 demo 视觉冲击拉满，但开发风险高
