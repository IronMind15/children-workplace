# 技术栈建议

> 面向"小学生 AI 产品"的通用技术选型建议，可直接复用到新项目。

## 一、技术栈全景

| 维度 | 选型 | 说明 |
|------|------|------|
| 前端 | Next.js 16 + React 19 + TypeScript | 全栈框架，前后端一体 |
| 样式 | Tailwind CSS v4 | 原子化 CSS，主题用 @theme 配置 |
| 组件 | 自建组件 + emoji 占位 | 图形后续换卡通插画 / Lottie |
| 后端 | Next.js Route Handlers（App Router） | 与前端同项目，无需分开部署 |
| 数据库 | SQLite（Node 内置 node:sqlite） | 零依赖、本地单文件 |
| 大模型 | DeepSeek API（deepseek-chat） | OpenAI 兼容格式，中文好、便宜 |
| 语音 | 规划：讯飞 / 阿里云 ASR + TTS | 未接入，儿童场景关键 |
| UI 设计 | 儿童风设计规范 | 大、圆、少、图>字、有反馈 |
| 部署 | 本地运行（demo），后续 Vercel / 云服务器 | 未部署 |
| 安全合规 | 内容审核、家长监管、防沉迷（规划中） | 未成年人产品上线前必须 |

## 二、为什么这样选型（关键决策）

1. **Next.js 全栈**：一个项目同时写前端 + 后端，最快出 demo。
2. **node:sqlite 而不是 better-sqlite3**：Node 24 内置 SQLite，零依赖、免编译（Windows 上 better-sqlite3 需要原生编译）。
3. **Tailwind v4**：主题写在 CSS 的 @theme 里，和设计规范一一对应。
4. **DeepSeek 用 OpenAI 兼容格式**：直接 fetch 调用，无需额外 SDK。
5. **先 emoji 后插画**：内容优先，图形最后再精细化。

## 三、设计规范建议

- 设计原则：大、圆、少、图>字、有反馈、有陪伴感。
- 具体配色 / 圆角值可随新项目主题自行定义（原项目用的橙色系仅作参考）。

## 四、大模型接入（DeepSeek）

- 接口地址：https://api.deepseek.com/chat/completions
- 模型：deepseek-chat
- 未配置 Key 时自动进入"演示模式"返回模拟回复，保证 demo 可跑。

接入步骤：

1. 到 https://platform.deepseek.com 申请 API Key
2. 把 key 填入 .env.local：`DEEPSEEK_API_KEY=sk-xxx`
3. 重启 dev 服务器（改 .env 必须重启才生效）

## 五、后续技术方向

1. 对话改流式输出（打字机式逐字显示）
2. 接语音（讯飞 / 阿里云 ASR + TTS）
3. 图形升级（emoji → 卡通插画 / Lottie）
4. 数据持久化（SQLite 存用户数据 / 进度 / 成就）
