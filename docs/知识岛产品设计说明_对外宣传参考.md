## 0. 一页纸摘要（给 PPT 封面 / 执行摘要）

**知识岛**是一款面向 1–6 年级小学生的**游戏化数学元认知学习产品**。

它把小学数学拆成 29 个「元认知原子」，让孩子在「驯服精灵、打小怪训练、净化渡海 Boss」的冒险旅程里，把数学知识**长进自己的脑子里**——而不是刷题背公式。

- **一句话定位**：把小学数学变成一座可以探险、可以收集的「知识岛」，让孩子在玩游戏的过程中，自然内化一套受用终身的「元认知」思维框架。
- **核心差异**：专业动作就是游戏动作——「识破题型 → 派克制精灵 → 多阶段拆招」，轻失败压力，全程有 AI 助手陪伴。
- **家长视角**：没有分数排名，只有「伙伴日记」用温柔的口吻讲孩子今天学到了什么。
- **技术底色**：单机本地、数据不出本机，天然契合儿童隐私保护。

## 1. 我们要解决什么问题（用户痛点 → 产品机会）

| 角色           | 真实痛点                        | 知识岛的解法                           |
| ------------ | --------------------------- | -------------------------------- |
| **孩子（主用户）**  | 刷题枯燥、记公式不懂「为什么」、学了不会用、怕错怕丢脸 | 冒险剧情驱动；答错只提示不判负；知识以「精灵」具象、可收集可进化 |
| **家长（次用户）**  | 想参与孩子学习，但只会看分数排名，亲子压力大      | 「伙伴日记」温柔共育，无分数、无排名，只见成长关键词       |
| **传统教育 App** | 「做题 + 奖励动画」两张皮，游戏性和专业性割裂    | 让专业动作本身成为游戏动作（识破题型=选克制精灵）        |

> **宣讲佐证句**：市面上多数数学 App 是「做题换金币」，知识岛是「把知识变成可以驯服的伙伴」——孩子记住的是一只精灵，背后是一个能迁移到任何题目的思维方法。

## 2. 核心理念：元认知 → 进化 → 精灵（产品的灵魂）

这是整个产品的设计原点，所有功能都从这里推导。建议在 PPT 用一页专门讲清楚。

### 2.1 什么是「元认知」

我们把小学数学（人教版 1–6 年级）的全部核心知识，拆成三种类型：

| 类型      | 本质           | 一句话           | 游戏化载体             |
| ------- | ------------ | ------------- | ----------------- |
| **元认知** | 操作原子（「会做什么」） | 能独立解题、能交叉出新知识 | **精灵**（收集 / 进化）   |
| **性质**  | 关于运算 / 图形的真理 | 不能独立解题，依附于元认知 | **觉醒 / 镀金**（金纹点亮） |
| **策略**  | 串起元认知的思想方法   | 解题套路，不产出新原子   | **连招**（图鉴 / 隐藏挑战） |

> 判据红线：能独立解一类题、又能作为父节点交叉出更新知识的，才是「元认知」。否则归为「性质」或「策略」。（这正是产品严谨之处：不是把知识点随便塞进游戏。）

### 2.2 双轴模型（知识如何「长大」）

- **组合轴（日常，无限）**：用已有的元认知排列组合，解具体问题（应用题、混合运算）——对应「打小怪训练」。
- **进化轴（结晶时刻，有限）**：少数组合「结晶」成新的元认知——对应「净化渡海 Boss，诞生新精灵」。
- **一句话**：组合是日常，进化是组合的「结晶时刻」。一次战斗往往两轴同时发生。

### 2.3 15 个「进化算子」（知识进化的规律）

进化不是随机的，遵循 15 种客观规律（反转 / 聚合 / 等分 / 扩域 / 升维 / 抽象 / 关系 / 显现 + 分类 / 表征 / 概率化 / 重叠 / 细化 / 变换 / 空间化）。例如：

- 加法 → 减法 = **反转**（倒过来用）
- 加法 → 乘法 = **聚合**（连加打包）
- 长度 → 面积 → 体积 = **升维**（多长一个维度）

> 这些算子既是知识图谱「边」的类型，也是游戏里关卡与精灵进化的设计模板，保证内容有据可循、体系自洽。

## 3. 产品价值主张（差异化竞争力）

1. **专业 = 游戏，不两张皮**：孩子「识破一道加法题 → 派出加法精灵（克制特效）→ 一步步拆招解题」，专业解题动作本身就是游戏战斗动作。
2. 低失败压力。答错只是伙伴温柔提示后重试——保护学习自信。
3. **AI 伙伴陪伴感**：唯一 AI 引导角色「小狐狸」，负责开场白、提示、鼓励、写家长日记，是「陪伴」而非「监工」。
4. **引导而不死板**：29 座岛构成一张进化大地图，孩子可自选路线，但每个出海口都标「前置本领」，形成探索感。
5. **温柔共育**：家长端是「伙伴日记」（第一人称成长摘要），无分数、无排名、无监控。
6. **隐私友好**：MVP 阶段数据仅存本地、不联网、无账号，天然契合儿童数据保护。

## 4. 核心体验旅程（用户一天 / 一次冒险怎么玩）

> 建议在 PPT 用一条「冒险时间轴」呈现，比文字更有冲击力。

```
创建小小探险家（纯点选，无打字）
        │
        ▼
🌊 世界地图（29 座岛，按知识进化铺开）
        │  点岛进入
        ▼
🏝️ 岛屿详情（打小怪训练 / 挑战渡海 Boss）
        │
        ├── 打小怪：识破题型 → 派克制精灵 → 多阶段拆招 → 星级结算（巩固，不出新精灵）
        │
        └── 渡海 Boss：观察 →「发现新元认知」→ 用新本领解题 → 净化结算
                  │
                  └── 一次性触发三件事（原子化）：
                      内化新元认知 + 诞生新精灵 + 解锁新岛（进化演出）
        │
        ▼

        │
        ▼
```

## 5. 内容体系（知识地图的体量，给 PPT 当「硬核背书」）

| 维度       | 规模       | 说明                                                          |
| -------- | -------- | ----------------------------------------------------------- |
| **元认知**  | **29 个** | 覆盖人教版 1–6 年级六大领域（数与运算 / 数的关系 / 代数 / 图形几何 / 量测 / 统计概率）+ 数学广角 |
| **进化算子** | **15 个** | 知识进化的客观规律（见 §2.3）                                           |
| **进化边**  | **31 条** | 双起点（计数 + 图形认识）、5 层有向无环图（DAG）                                |
| **觉醒性质** | **30 条** | 覆盖 24/29 元认知，其中 13 条为「多精灵觉醒」                                |
| **策略**   | **19 条** | 简算 / 验算 / 估算 / 画图 / 逆向 / 数学广角 8 主题等                         |

**结构亮点**：一张「知识进化大地图」——上游岛净化后点亮下游岛，孩子看得见「我今天学的，是明天那座岛的地基」。知识不再是孤立考点，而是一条会生长的故事线。

> 数学广角（鸡兔同笼、植树、鸽巢、优化、搭配推理等）设计为**隐藏挑战 / 彩蛋**，不进主线，奖励更丰厚，供学有余力的孩子探索——这是「分层不分层」的巧思。

## 6. 视觉与界面设计语言（PPT 视觉页的根据）

### 6.1 整体风格

- **方向**：暖色手绘 / 童书插画风（毛绒卡通），温暖、低饱和、有故事感。
- **色彩板（取自设计稿量化取色，可直接给设计师对齐）**：
  - 主背景 `#fdfceb` 米黄
  - 主强调 `#f79228` 橙
  - 次强调 `#96e3eb` 青
  - 草地 `#d4e790` 黄绿
  - 暗部 `#14161b` 近黑
- **字体**：标题用童趣字体（ZCOOL KuaiLe 类），正文保留系统字体保可读性。

### 6.2 角色体系（IP 资产，对外可重点展示）

- **小狐狸（伙伴 / 引导者）**：唯一 AI 陪伴角色，开场白、鼓励、写家长日记的载体。
- **精灵（我方）**：元认知具象，**1 只精灵 = 1 个元认知**；按所属领域分 **7 套模板 × 4 形态**（熟练度 1–4 对应进化形态）。
- **小怪 / 渡海 Boss / 知识守卫**：分别代表训练关、进化关、本岛觉醒练习关。

### 6.3 三层地图结构（核心界面叙事）

| 层              | 是什么                                 | 视觉来源       |
| -------------- | ----------------------------------- | ---------- |
| **L1 世界地图** 🔧 | 一屏看 29 岛的进化全景；未解锁岛叠雾、已解锁清晰          | 童书风岛屿插画缩略图 |
| **L2 岛屿详情** 🔧 | 点岛放大进入，2.5D 俯视底图，岛上分布小怪 / Boss / 守卫 | 岛屿背景插画     |
| **L3 战斗** ✅    | 识破题型 → 派精灵 → 拆招结算                   | 战斗演出       |

**雾效规则（巧思）**：未解锁 = 重雾 + 🔒；部分解锁（岛亮了但还有 Boss 没净化）= 轻雾；已解锁 = 清晰。三种状态全靠运行时 CSS 生成，**一套图撑起全部解锁进度表达**。

**三种地图模式（可并存）**：① 分页地图（逐片探索，左右翻页）② 全览缩略图（一屏看全局）③ 谱系树（滚动看进化路线）。

### 6.4 外壳与信息架构（📐 设计中）

- 顶栏中间主 tab：**地图 / 跟小狐狸聊（AI）** 二选一全宽。
- 右上角头像 = 「我的」入口，点击展开抽屉承载：精灵图鉴 / 知识家园 / 成就 / 家长端 / 设置。
- 宽屏（≥1280px）可切换「左地图 + 右 AI 聊」分屏，边玩边问。

### 6.5 小学生友好尺寸规范（体现「为孩子设计」）

- 点击目标 ≥ **56×56 px**（儿童指尖约 12mm）；最小正文字号 **18px**、标题 28–32px。
- 图标 + 文字双标签永远同时出现；间距防误触。

## 7. 特色系统（PPT 的「记忆点」页）

1. **觉醒系统 🔜 规划中**：孩子沿主线推进时，旧本领不断深化——精灵图鉴金纹逐条点亮（交换律、分配律、三角形内角和……）。它也是「卡在渡海 Boss 时」的成长退路：同一 Boss 失败 ≥2 次引导觉醒，给孩子一条不卡关的进步路径。
2. **知识迁移 / 合体进化 🔜 规划中**：多个旧元认知交叉，合成全新能力（如「平均数 = 加法 + 除法」）。游戏表现为**多只精灵合力净化一个 Boss**——把「组合旧知、迁移出新能力」显化成一个高光时刻。
3. **知识守卫 🔜 规划中**：每座岛的觉醒练习载体（本岛本领的守护者），承接觉醒后的内容升级。
4. **数学广角隐藏挑战 🔜 规划中**：彩蛋式额外挑战，奖励更丰厚。

> 对外表述建议：把这四项作为「产品 roadmap 亮点」呈现，明确标注「即将上线」，不要说成已上线。

## 8. 技术底座（PPT 一笔带过即可）

- **栈**：Next.js + React + Tailwind + 本地 SQLite。
- **隐私**：MVP 单机本地、数据不出本机、无账号无第三方追踪——天然契合儿童数据保护，可作合规卖点。
- **演进**：架构预留「多学科迁移」（语文 / 英语……）与「知识迁移」进阶玩法，未来可长成「各种知识都能这样学」的平台。
