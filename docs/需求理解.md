# 知识岛 · 需求理解（对齐稿）

> 这份文档记录"我们到底在做什么"的共识，作为后续《需求文档》的输入。
> 状态：已与发起人对齐确认。

## 一、一句话定位

做一个给**小学生（1~6 年级）**用的、叫「知识岛」的 AI 产品——核心不是"刷题"，而是让孩子**驯养一个自己造的 AI 伙伴，通过打怪来学习**，在陪伴中顺便学会"驾驭 AI"。

## 二、目标用户

- **主要用户**：1~6 年级小学生
- **次要用户**：家长（温柔共育，非监控）

## 三、核心世界观

- **每个知识点 = 一只怪物**，新怪物从旧怪物演化而来（加法 → 减法 → 乘法 …）
- 学习路径被重构成一张**怪物谱系树**，打怪 = 爬学习路径

## 四、战斗 / 学习方式

- 战斗的核心动作是**"识别血缘 + 调兵"**：认出它和哪个旧怪像、该调用哪个知识卡——练的是"元认知"和"指挥 AI"，不是单纯算答案
- 全程**鼠标点击**，杜绝打字（低龄孩子打字慢）

## 五、伙伴（陪伴感）

- 孩子**亲手造伙伴**（名字 / 样子 / 性格 / 特长），并有一个**"大脑编辑器"**（开关调 AI 性格）——这是"驾驭 AI"的落地
- 伙伴**会成长、会进化、有记忆**，是"活的成长档案"，陪伴感 > 工具感
- 伙伴会说话（气泡短台词，以后接 TTS），但孩子用点击回应，**不做聊天 UI**

## 六、家长端

- 温柔共育：家长通过"伙伴日记"了解孩子成长，入口不显眼，不出现分数排名
