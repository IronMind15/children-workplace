## 1. 读图约定

### 1.1 三条「线」分别指什么

| 线        | 载体               | 是什么       | 触发                    |
| -------- | ---------------- | --------- | --------------------- |
| **进化路线** | 元认知 → 元认知（DAG 边） | 旧知交叉诞生新原子 | 净化渡海 Boss             |
| **觉醒路线** | 元认知 → 性质（金纹）     | 旧知深化、附加理解 | 主线推进 / 卡关 / 熟练度       |
| **连招路线** | 策略（思想方法）         | 串起多个元认知解题 | 隐藏挑战（见《第二阶段》§6，本文不展开） |

> 一句话：**进化是「长出新本领」（新精灵），觉醒是「把老本领学得更透」（镀金）**。进化推进主线，觉醒是主线的蓄力与退路。

### 1.2 进化算子（15 个，边的类型）

**核心算子（8 = 7 主 + 1 副，主司「数与运算」）：**

| # | 算子    | 机制       | 一句话解释（给孩子听的版本）       |
| - | ----- | -------- | -------------------- |
| 1 | 反转    | 反过来操作    | 倒过来用：会加就会减，会乘就会除     |
| 2 | 聚合    | 重复操作打包   | 重复着用、再打包起来：连加变乘法     |
| 3 | 等分    | 整体分成若干份  | 把整体平均分开：分出来就是分数      |
| 4 | 扩域    | 数域向外延展   | 把数的天地向外扩一圈：整数→小数、正→负 |
| 5 | 升维    | 度量维度 +1  | 多长出一个维度：长度→面积→体积     |
| 6 | 抽象    | 符号替代具体数  | 把具体的数变成符号：运算→字母→方程   |
| 7 | 关系    | 表达两量比较   | 拿两个量比一比：除法→比、分数→百分数  |
| 8 | 显现（副） | 交叉时显形出规律 | 交叉时显形出规律：乘法×加法→分配律   |

**领域算子（7，主司「几何 / 统计 / 量测」）：**

| #  | 算子  | 机制        | 一句话解释           |
| -- | --- | --------- | --------------- |
| 9  | 分类  | 按属性分组     | 按属性分分组：数东西前先归类  |
| 10 | 表征  | 数据 → 图形   | 把数据画成图：一眼看清     |
| 11 | 概率化 | 确定 → 随机   | 猜一猜可能性          |
| 12 | 重叠  | 分类时发现交集   | 分着分着发现重叠：集合     |
| 13 | 细化  | 整体 → 局部特征 | 把图形看得更细：图形→角    |
| 14 | 变换  | 对图形施加操作   | 让图形动起来：平移/旋转/对称 |
| 15 | 空间化 | 图形 → 空间定位 | 在空间里找准位置        |

### 1.3 符号说明

- `A ──算子──→ B`：元认知 B 由 A 通过该算子进化而来。
- 一个节点多个父（如 平均数 = 加法 + 除法）= **合体进化 / 知识迁移**，Boss 需要多只精灵合力净化。
- 觉醒条目按教育顺序排列（先学哪条在前）；`→` 表示先后顺序。

## 3. 进化路线 + 觉醒路线 · 逐元认知详解

> 每条 = 含义 / 进化自（算子 + 为什么这条边成立）/ 进化到 / 觉醒（性质 + 顺序 + 解释）。

### 3.1 数与运算（MK-01 ~ MK-10，MK-37）

**MK-01 计数 ★ 起点**

- 含义：数数的产生——「1、2、3…」把一堆东西数清楚。
- 进化自：无（起点，孩子天生会数数）。
- 进化到：位值（聚合）、加法（聚合）、时间（聚合）、分类整理（分类）。
- 觉醒：无（起点，暂不配性质）。

**MK-02 位值**

- 含义：十进制、数位——同样的数字在不同的位上表示不同的数。
- 进化自：计数 ──聚合──（数好的果子 10 个捆成一捆，满十进一，产生「位」）。
- 进化到：小数（扩域）、单位换算（扩域）、因数倍数（细化）。
- 觉醒：**PP-15 十进制规则**——逢十进一，满十向高位移一。（理解 23 = 2 个十 + 3 个一）

**MK-03 加法**

- 含义：合并求总数——两堆合一起数。
- 进化自：计数 ──聚合──（会数数后，「再数 3 个」打包成一次合并）。
- 进化到：减法（反转）、乘法（聚合）、字母表示数（抽象）、平均数（聚合，合体）。
- 觉醒顺序：**PP-01 加法交换律**（换序和不变，先学）→ **PP-02 加法结合律**（先加谁和不变，后学）。

**MK-04 减法**

- 含义：求差 / 去掉 / 逆运算——拿走了几个还剩几个。
- 进化自：加法 ──反转──（「5 个拿走 2 个」是「2+?=5」倒过来想）。
- 进化到：负数（扩域）、字母表示数（抽象）。
- 觉醒：**PP-10 减法性质**——连减 = 减去它们的和（a-b-c = a-(b+c)）。

**MK-05 乘法**

- 含义：连加的打包——3 个 4 不用一个个加。
- 进化自：加法 ──聚合──（连加打包：4+4+4 写成 3×4）。
- 进化到：除法（反转）、因数倍数（关系）。
- 觉醒顺序：**PP-03 乘法交换律**（换序积不变）→ **PP-04 乘法结合律**（先乘谁积不变）→ **PP-05 乘法分配律**（乘开括号，a×(b+c)=a×b+a×c；交叉引用加法）。

**MK-06 除法**

- 含义：平均分 / 逆运算——一大袋糖每人一样多。
- 进化自：乘法 ──反转──（「每人 4 个、3 人共 12 个」倒过来问「12 个分 3 人」）。
- 进化到：分数（等分）、比（关系）、平均数（等分，合体）。
- 觉醒：**PP-07 商不变规律**——被除数除数同乘同除，商不变（如 12÷3 = 120÷30）。

**MK-07 分数**

- 含义：部分与整体——蛋糕切成 4 块吃掉 1 块。
- 进化自：除法 ──等分──（平均分产生「一份」的表达）。
- 进化到：小数（扩域）、百分数（关系）。
- 觉醒：**PP-08 分数的基本性质**——分子分母同乘同除，分数大小不变（约分 / 通分的依据）。

**MK-08 小数**

- 含义：十进分数——把分数搬进十进制的位子。
- 进化自：分数 ──扩域── + 位值 ──扩域──（合体：分数 ÷ 十进制位值）。
- 进化到：无（顶点之一）。
- 觉醒：**PP-11 小数的性质**——末尾添 0 / 去 0，大小不变（3.5 = 3.50）。

**MK-09 百分数**

- 含义：比率——把「整体」定成 100 份来比。
- 进化自：分数 ──关系──（拿分数跟 100 份比一比）。
- 进化到：无（顶点之一）。
- 觉醒：**PP-14 百分数互化**——百分数 ↔ 分数 / 小数 的转换规则（90% = 0.9 = 9/10）。

**MK-10 负数**

- 含义：相反意义的量——零上零下、盈利亏损。
- 进化自：减法 ──扩域──（减过头了怎么办？往零下面扩）。
- 进化到：无（顶点之一）。
- 觉醒：无（暂不配）。

**MK-37 因数倍数**（第二阶段新增，真元认知）

- 含义：整除关系——6 = 1×6 = 2×3，每个数都有自己的因数。
- 进化自：乘法 ──关系── + 位值 ──细化──（合体：乘法拆出因数，位值细化出倍数规律）。
- 进化到：无（为约分 / 通分 / 判质数打地基）。
- 觉醒顺序：**PP-12 整除特征**（2 / 5 / 3 / 9 的倍数特征：看个位、看数字和）→ **PP-13 质数与合数**（质数只有 1 和它本身两个因数）。

### 3.2 数的关系（MK-11 ~ MK-12）

**MK-11 比**

- 含义：两个量的比值关系——6 个苹果对 3 个橘子是 2:1。
- 进化自：除法 ──关系──（两个数量除一除，比出倍数关系）。
- 进化到：比例（关系）。
- 觉醒：**PP-16 比的基本性质**——前项后项同乘同除，比值不变（化简比的依据）。

**MK-12 比例**

- 含义：正比例 / 反比例——两个比牵起手来相等。
- 进化自：比 ──关系──（2:3 与 4:6 相等，组成比例）。
- 进化到：无（顶点之一）。
- 觉醒：**PP-17 比例的基本性质**——内项积 = 外项积（解比例的钥匙）。

### 3.3 代数初步（MK-13 ~ MK-14）

**MK-13 字母表示数**

- 含义：用符号代表未知量——数不知道就让字母来当它。
- 进化自：加法 ──抽象── + 减法 ──抽象──（合体：把具体运算里的数换成符号）。
- 进化到：方程（抽象）。
- 觉醒：无（暂不配；运算律的符号化表达可作为进阶内容）。

**MK-14 方程**

- 含义：等式关系 + 求未知数——把不知道的数放进等式里解出来。
- 进化自：字母表示数 ──抽象──（x+4=9，x 是几）。
- 进化到：无（顶点之一）。
- 觉醒：**PP-06 等式性质**——两边同加减乘除，等式仍成立（解方程每一步的依据）。

### 3.4 图形与几何（MK-15 ~ MK-21）

**MK-15 图形认识 ★ 起点**

- 含义：平面 / 立体图形的特征——三角形 3 条边、球圆滚滚。
- 进化自：无（起点）。
- 进化到：周长（升维）、角（细化）、图形运动（变换）、位置与方向（空间化）。
- 觉醒：无（起点，暂不配；具体图形的度量规律挂在后续度量元认知上）。

**MK-16 角**

- 含义：两条射线的开合——直角 90°、锐角、钝角。
- 进化自：图形认识 ──细化──（把图形看得更细：两条边张开成角）。
- 进化到：无（顶点之一）。
- 觉醒：**PP-18 三角形内角和 = 180°**——任何三角形三个角加起来都是 180°。

**MK-17 周长**

- 含义：一维边界的度量——沿图形边走一整圈。
- 进化自：图形认识 ──升维──（从「认图形」到「量图形的一圈」）。
- 进化到：面积（升维）。
- 觉醒：**PP-19 圆周长 = 2πr**——圆的一圈 = 直径 × π。

**MK-18 面积**

- 含义：二维大小的度量——给图形铺满小方块。
- 进化自：周长 ──升维──（从「量一圈」到「铺满」）。
- 进化到：体积（升维）。
- 觉醒顺序：**PP-20 圆面积 = πr²**（圆的面积 = 半径平方 × π）→ **PP-21 面积公式推导链**（平行四边形割补成长方形 → 三角形 / 梯形各取一半）。

**MK-19 体积**

- 含义：三维空间的度量——往立体里装小方块。
- 进化自：面积 ──升维──（从「铺满面」到「装满空间」）。
- 进化到：无（顶点之一）。
- 觉醒：**PP-22 圆柱与圆锥体积关系**——等底等高时，圆锥体积 = 圆柱的 1/3。

**MK-20 图形运动**

- 含义：平移 / 旋转 / 对称——让图形动起来。
- 进化自：图形认识 ──变换──（对图形施加操作）。
- 进化到：无（顶点之一）。
- 觉醒：**PP-23 图形变换不变性**——平移 / 旋转 / 对称不改变形状与大小。

**MK-21 位置与方向**

- 含义：空间方位 / 数对坐标——面向北，右手边是东。
- 进化自：图形认识 ──空间化──（图形在空间里找准位置）。
- 进化到：无（顶点之一）。
- 觉醒：无（暂不配）。

### 3.5 量与测量（MK-22 ~ MK-23）

**MK-22 单位换算**

- 含义：长度 / 质量 / 时间 / 货币换算——米变厘米、元变角。
- 进化自：位值 ──扩域──（十进制搬家到单位上）。
- 进化到：无（顶点之一）。
- 觉醒：**PP-24 进率规律**——相邻单位：长度 ×10、面积 ×100、体积 / 质量 ×1000。

**MK-23 时间**

- 含义：时刻与经过时间——从 3 时到 5 时过了 2 小时。
- 进化自：计数 ──聚合──（秒聚成分、分聚成时，数数数出新进制）。
- 进化到：无（顶点之一）。
- 觉醒：**PP-25 时间进制**——60 秒 = 1 分、60 分 = 1 时（不是十进制！）。

### 3.6 统计与概率（MK-24 ~ MK-28）

**MK-24 分类整理**

- 含义：数据收集与分类——数东西之前先归类。
- 进化自：计数 ──分类──（按属性分分组）。
- 进化到：统计图（表征）、可能性（概率化）、集合（重叠）。
- 觉醒：无（基础型，暂不配）。

**MK-25 统计图**

- 含义：条形 / 折线 / 扇形——数据画成图一眼看清。
- 进化自：分类整理 ──表征──（整理好的数据画成图）。
- 进化到：无（顶点之一）。
- 觉醒：无（选图规则属于「表征策略」，见《第二阶段》§6）。

**MK-26 平均数**

- 含义：集中趋势——先合起来再平均分，代表大家水平。
- 进化自：加法 ──聚合── + 除法 ──等分──（合体：总和 ÷ 个数）。
- 进化到：无（顶点之一）。
- 觉醒顺序：**PP-26 平均数关系**（总和 = 平均数 × 个数）→ **PP-27 中位数**（有序数据最中间的值）→ **PP-28 众数**（出现次数最多的值）。

**MK-27 可能性**

- 含义：概率直觉——10 个红球 1 个白球更容易摸到红球。
- 进化自：分类整理 ──概率化──（分类后问「随机摸到哪个」）。
- 进化到：无（顶点之一）。
- 觉醒：**PP-29 概率范围**——概率在 0~1 之间；必然 = 1，不可能 = 0。

**MK-28 集合**

- 含义：重叠关系（容斥）——既喜欢苹果又喜欢香蕉放哪个圈。
- 进化自：分类整理 ──重叠──（分着分着发现两堆有交集）。
- 进化到：无（顶点之一）。
- 觉醒：**PP-30 容斥规则**——重叠部分只能数一次（韦恩图计数）。
