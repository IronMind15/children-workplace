# 知识岛 · 数据区分说明

> 目的：明确「项目运行要用的数据」与「只存在本地的素材/数据」的边界，避免混淆、误删、误传。

## 一、项目运行数据（游戏跑起来必须的，随项目走）

| 路径 | 内容 | 说明 |
|------|------|------|
| `data/app.db` | 游戏进度库（种子 + 玩家进度） | 运行时自动生成/迁移，**gitignore 不入库**；删掉后首次启动会重新初始化（进度清零） |
| `public/monsters/*.webp` | 小怪/Boss 压缩图（12 张） | 游戏内实际使用的图片，**已在 git** |
| `public/sprites/*.webp` | 精灵压缩图（8 张） | 同上 |
| `app/ components/ lib/` | 全部代码 | git 管理 |
| `docs/需求文档.md` 等 5 份文档 | 需求/设计文档 | git 管理 |

## 二、本地备份素材（仅本机留存，不入 git、不随项目走）

| 路径 | 内容 | 说明 |
|------|------|------|
| `assets_backup/` | **原始 PNG 图**（monsters 12 + sprites 8，15MB） | WebP 压缩前的原图备份；游戏内已改用压缩版，这里仅作留存，**可随时删除** |
| `docs/112初版/` | UI 设计稿 1.0（41 张，49MB） | 页面稿/岛屿图/怪物图原始素材，**gitignore 不入库** |
| `docs/113背景/` | 岛屿背景图（19 张，16MB） | 第二层岛屿详情背景素材，**gitignore 不入库** |
| `.workbuddy/` | AI 会话记忆 | 项目私密记忆，**gitignore 不入库，不要发给别人** |
| `data/app.db.bak` 等备份 | 数据库历史备份 | 防误操作留档，可清理 |

## 三、决策规则（一句话）

- **要发别人 / 提交 git**：代码 + `public/*.webp` + 文档（约 15MB）
- **只留自己机器**：`assets_backup/`（PNG 原图）、`docs/112初版`、`docs/113背景`、`.workbuddy/`（AI 记忆）、`data/*.db`（进度）
- **可以安全删除**：`assets_backup/`、`docs/112初版`、`docs/113背景`、`data/*.bak*`——删了不影响游戏运行（运行时只依赖 `data/app.db` + `public/*.webp`）

## 四、迁移到第三层地图后的资源变化（待实施）

- 第一层世界地图：112初版 岛屿图（有雾/无雾）→ 压缩 WebP 进 `public/islands/`（映射待设计师确认）
- 第二层岛屿详情：113背景 19 张 → 压缩 WebP 进 `public/island-bg/`（映射待确认）
- 原图继续留在 `docs/112初版`、`docs/113背景` 作本地留存
