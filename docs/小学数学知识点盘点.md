## 一、课标框架：四大领域 × 三学段

2022 版课标将小学数学分为 **4 大领域 × 3 学段**（1-2 / 3-4 / 5-6 年级），每个领域按「内容要求 / 学业要求 / 教学提示」三层呈现。

| 领域 | 第一学段（1-2 年级） | 第二学段（3-4 年级） | 第三学段（5-6 年级） |
|------|------|------|------|
| **数与代数** | 数与运算、数量关系 | 数与运算、数量关系 | 数与运算、数量关系 |
| **图形与几何** | 图形的认识与测量 | 图形的认识与测量、图形的位置与运动 | 图形的认识与测量、图形的位置与运动 |
| **统计与概率** | 数据分类 | 数据的收集、整理与表达 | 数据的收集、整理与表达、随机现象发生的可能性 |
| **综合与实践** | 主题式学习 | 主题式学习 | 主题式学习 |

> ⚠️ 2022 课标变化：数与代数由 5 主题整合为「数与运算 + 数量关系」；负数、方程、反比例移到初中（但人教版教材仍在小学阶段涉及基础内容）；新增「计数单位」统领整数/小数/分数运算一致性；强调代数推理（等量的等量相等、总量等于各分量之和）。

## 四、典型应用题专题（跨年级综合）

这类题型是数学知识综合运用的载体，也是易错重灾区。

### 4.1 归一/归总问题（3-4 年级）

- **归一**：先求单一量（1 份），再求总量。如「3 支笔 12 元，5 支多少元？」→ 12÷3×5=20
- **归总**：先求总量，再分配。如「每箱 20kg，5 箱共多少？」→ 20×5=100
- **易错点**：混淆单一量与总量，未先求「1 份量」

### 4.2 行程问题（4-6 年级）

- 基本关系：路程 = 速度 × 时间
- 相遇问题：路程和 = 速度和 × 时间
- 追及问题：路程差 = 速度差 × 时间
- 环形跑道：同向相遇时间 = 周长 ÷ 速度差

### 4.3 分数/百分数应用题（5-6 年级）

- 核心技巧：找准单位「1」（「是/占/比」后面通常是单位 1）
- 已知单位 1 用乘法，求单位 1 用除法或方程
- 易错点：混淆分率与具体数量；量率错位

### 4.4 工程问题（6 年级）

- 总工程量 = 1，工效 = 1/时间，合作工效 = 各工效之和
- 易错点：合作时工效相加而非时间相加

### 4.5 和差倍问题（3-5 年级）

- 和差：（和+差）÷2=大数，（和-差）÷2=小数
- 和倍：和÷(倍数+1)=小数
- 线段图是核心辅助工具

### 4.6 鸡兔同笼变形（4 年级+）

- 假设法公式：假设全为 A，总量差÷单差 = B 的数量
- 可扩展到各类「两物混合」问题

## 五、常见量与单位换算总表

### 5.1 长度

千米(1000)→米(10)→分米(10)→厘米(10)→毫米

### 5.2 面积

平方千米(100)→公顷(10000)→平方米(100)→平方分米(100)→平方厘米

### 5.3 体积/容积

立方米(1000)→立方分米(=升)(1000)→立方厘米(=毫升)

### 5.4 质量

吨(1000)→千克(1000)→克

### 5.5 人民币

元(10)→角(10)→分

### 5.6 时间

时(60)→分(60)→秒；年→月→日

> **易错点**：面积单位进率是 100（非 10），体积单位进率是 1000（非 100）。大单位→小单位乘进率，小单位→大单位除以进率。

| 缺口领域 | 具体知识点 | 优先级 | 理由 |

### 6.3 题目丰富度差距

- **前段（加减乘除计数位值）**：故事模板多、题型变化丰富

- **数学广角**：完全空白

## 七、螺旋上升脉络（知识演进路径）

小学数学知识不是零散堆砌，而是环环相扣的「知识链」：

### 7.1 数的演进

```
20以内整数 → 100以内 → 万以内 → 大数（亿级）
          ↘ 分数（三上初步 → 五下意义性质）
          ↘ 小数（三下初步 → 四下意义性质 → 五上运算）
          ↘ 百分数（六上）→ 负数（六下）
```

### 7.2 运算演进

```
加减法（一上）→ 乘除法（二上）→ 四则混合（四下）
→ 小数四则（五上）→ 分数四则（六上）→ 运算定律（四下）
```

### 7.3 图形演进（从 2D 到 3D）

```
认识图形（一上）→ 周长（三上）→ 面积（四下/五上）→ 体积（五下/六下）
→ 图形运动（五下）→ 圆与扇形（六上）→ 圆柱圆锥（六下）
```

### 7.4 统计演进

```
分类（一上）→ 统计表（二上）→ 条形图（三上）→ 复式条形（四上）
→ 折线图（五下）→ 扇形图（六上）→ 平均数/中位数/众数（六下）
```

> 这条脉络正好契合「知识岛」的进化图谱设计——前一层进化出后一层，多父汇聚。

## 八、对「知识岛」后端的建议方向（仅记录，不改项目）

1. **补数学广角**：9 个缺失主题都是元认知策略的天然载体，优先补「鸡兔同笼/植树问题/优化/推理」4 个高价值主题
2. **补因数倍数**：五年级核心，质数合数/公因数公倍数，是分数运算的地基
3. **补运算定律**：四年级核心，简便计算
4. **充实后段题目**：图形几何/统计概率的出题函数加更多变化（参照加减法的多故事模板）
5. **属性/策略系统**：基于数学广角的思想方法（排列组合/逻辑推理/集合/优化/假设建模/化归/数形结合/抽屉模型）设计策略属性
