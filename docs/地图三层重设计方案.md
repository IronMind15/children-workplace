## 四、雾效规则（运行时叠加，不烧进图）

你原话「未解锁的岛屿用雾来装饰，已解锁的岛屿则去掉雾」——雾是**装饰（overlay）**，不是图的两种版本。渲染时按状态叠加：

- `unlocked = true` → 清晰原图；
- `unlocked = false` → **重雾**：`blur(2px)` + 亮度压暗 + 半透明白雾层 + 🔒 角标；
- **部分解锁**（岛已点亮、但岛内仍有未净化 Boss）→ **轻雾**：`blur(1px)` 不压暗，提示「可进但还有挑战」。

好处：只需 19 张插画，三种锁定态全靠 CSS 生成，无需为每种态准备两套图。
